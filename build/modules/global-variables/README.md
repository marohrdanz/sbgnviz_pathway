
# Generate Global Variables Section of Pipeline Report

This directory is used to generate the normally invisible
"global variables" section of the pipeline report.

The "global variables" section loads the Metabolite Name Key, the metadata, the covariate data (pData),
and the experiment data into modules that can be accessed via the global variable $PIPE.
The modules provide functions for accessing the loaded data.

$PIPE also provides access to some generic utility functions and the jStat statistical package.

The "global variables" section also runs data validation checks on the loaded
data, and adds details of any failed checks to the "data-error" section of
the report (and makes that section visible).

## Generate HTML and add to report

Inclusion of this section into the final report occurs in two stages:

1. A single HTML file is generated by `scripts/generate_global_variables.sh` (which is
   run from `scripts/pipeline_processing.R`).  The script sets four global variables:
   the full paths to the metadata, covariate data (pData), and pipeline data files
   and the directory in which to save the generated HTML file.  It then runs
   `npm run build` which uses webpack to combine the section's index.html and javascript
   files into a single HTML file that is output to `$OUTPUT_DIR/index.html`.

2. `$OUTPUT_DIR/index.html` is incorporated into the final report by `scripts/child_templates/global-variables.Rmd`
   which is invoked from `scripts/pipeline_report_template.Rmd`.
