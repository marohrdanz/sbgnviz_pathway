# SBGNViz Pathway

This repo builds several moudules used by the xPEDITE reporting system
developed by researchers at The University of Texas MD Anderson Cancer Center.

## Usage

The modules in this repo are used by the [xPEDITE](https://github.com/MD-Anderson-Bioinformatics/xpedite) pipeline.

To use, build this image with:

```bash
docker-compose build
```

The resulting image is used by the xPEDITE (see the docker-compose.yml
in the [xPEDITE](https://github.com/MD-Anderson-Bioinformatics/xpedite) repo.)
